## 🔭 Current Projects
- **[Mood2Music](https://github.com/ss1705/Mood2Music)** — Mood-based music recommender with a hybrid retrieve-then-rerank architecture: sentence-transformer + FAISS retrieval, CLAP audio embeddings for energy/arousal signal, and a valence-arousal-penalty reranker (NRC VAD Lexicon) on top. Live at [mood2-music.vercel.app](https://mood2-music.vercel.app)
- **[NYC Taxi Real-Time Demand Pipeline](https://github.com/ss1705/nyc-taxi-streaming-pipeline)** — Kafka (KRaft) → PySpark Structured Streaming → DuckDB → 3-layer dbt model → Streamlit/Altair dashboard, deployed on Railway. Prophet forecasting layer in progress
- **Task-Aware Orchestration for LLM Councils** — Semester-long research project on task-aware LLM routing; built Python tooling to evaluate accuracy, latency, and cost across 12 LLMs, 5 benchmarks, and 4 routing policies on USC CARC HPC
- **SDOH Bias in LLM Clinical Responses** — Prompt-based bias evaluation framework across 3 LLMs and 5 SDOH conditions on 4 clinical dimensions; presented at ShowCAIS 2026, USC
- **Job Application Tracker** — FastAPI + APScheduler service that parses job application emails via the Gmail API, extracts structured fields with LLaMA 3.1 via Groq, validates with Pydantic, and syncs nightly to a Google Sheet
